AI 코딩 도구 보안 및 비용 검토
2026. 9. 30
1. 검토 배경
 □ 파일럿 결과(작업 시간 평균 18% 단축)를 바탕으로 전사 확대 도입 전 보안 및 비용 검토
 □ 쟁점 : 사내 소스 외부 전송 위험, 라이선스 비용, 도입 방식

2. 도입 방식 비교
구분	(1안) 외부 클라우드 서비스 이용	(2안) 사내 전용 환경 구축
보안	소스 일부가 외부 서버로 전송됨	사내망 내에서 처리, 외부 전송 없음
비용	1석당 월 25만원 / 150석 기준 연 4.5억원	초기 구축비 12억원 / 운영비 연 3억원
구축 기간	즉시 사용 가능	약 6개월
기술 수준	최신 모델 즉시 반영	모델 업데이트 주기에 따라 지연 가능

3. 검토 의견
 □ 보안심사 상태 : 외부 전송 데이터 범위 제한 조건부로 심사 진행 중 (9월 말 완료 예정이었으나 일정 연장)
   - 전송 대상에서 핵심 알고리즘 및 고객 데이터 저장소 제외 조건 검토
 □ 비용 측면
   - 1안은 초기 부담이 적으나 석수 증가에 비례해 비용 증가
   - 2안은 3년 누적 기준 21억원(초기 12억원 + 운영 3억원 × 3년)으로, 1안 3년 누적 13.5억원보다 높음
     ※ 3년 누적 기준 약 233석을 넘으면 2안이 유리 (21억원 ÷ 석당 900만원, 2안 운영비가 석수와 무관하다는 가정)
 □ 파일럿에서 확인된 보안 관련 지적 3건 증가는 전용 보안 점검 도구 병행으로 대응 가능한지 추가 확인 필요

4. 제 언
 □ 1단계로 1안 기반 150석 도입, 보안 조건을 충족하는 범위로 한정
 □ 2안은 석수가 300석으로 늘어나는 시점에 재검토
   ※ 최종 결정은 보안심사 결과 확정 후 진행
