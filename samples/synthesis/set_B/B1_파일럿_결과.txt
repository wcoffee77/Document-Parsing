AI 코딩 도구 파일럿 운영 결과
2026. 9. 18
1. 추진 개요
 □ 개발 생산성 제고를 위해 AI 코딩 도구 파일럿 운영
   - 기간 : 2026. 7. 1 ~ 8. 29 (8주)
   - 대상 : 소프트웨어 개발 조직 3개 팀, 총 80명 (전체 개발 인력 420명의 19%)
 □ 평가 항목 : 작업 완료 시간, 코드 리뷰 지적 건수, 사용자 만족도

2. 운영 결과
 □ 작업 완료 시간 단축 : 평균 18% (신규 기능 개발 24%, 버그 수정 12%)
   - 테스트 코드 작성 시간은 31% 단축
 □ 코드 리뷰 지적 건수 : 1인당 월 평균 9.2건 → 7.4건 (20% 감소)
   - 다만 보안 관련 지적은 파일럿 기간 중 3건 증가
 □ 사용자 만족도 : 5점 만점 4.1점, 지속 사용 의향 88%
 □ 활용 현황
   - 주 3회 이상 사용자 : 62명 (78%)
   - 미사용자(주 1회 미만) : 9명, 주요 사유는 사내 레거시 코드와의 낮은 호환성

3. 문제점
 □ 생성 코드에 사내 소스가 외부로 전송될 가능성에 대한 우려 제기 (설문 응답자의 41%)
 □ 레거시 언어(C/C++ 기반 내부 프레임워크)에서는 제안 정확도가 낮아 효과 제한
   - 해당 영역의 작업 시간 단축은 4%에 그침
 □ 도구 사용 격차에 따라 팀 간 생산성 편차 발생
   ※ 상위 팀 25% 단축 대비 하위 팀 9% 단축

4. 향후 계획
 □ 보안 검토 후 확대 도입 여부 결정 (보안심사 진행 중)
 □ 레거시 코드 대응을 위한 사내 코드 학습 가능 여부 검토
   ※ 확대 도입 시 예산은 별도 검토 예정
