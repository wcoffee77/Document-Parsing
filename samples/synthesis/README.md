# 다문서 종합(D단계) 시험지 (가상 문서)

실제 내용이 아닌 가상 문서다. 이름·수치는 모두 지어낸 것이다. 사람이 고친 정답을 `정답_*.txt`로 두면 변환기 결과와 비교한다.

| 세트 | 원문 3건 | 주제 | 일부러 넣은 시험 요소 |
|---|---|---|---|
| set_A | A1 수급현황(9/12) → A2 대체공급사 검토(9/26) → A3 재고·비용 대응(10/2) | 반도체 장비 부품 공급 리스크 | 같은 값의 시점별 갱신(리드타임 26→28주, 재고 210→180개, 소진 11월 3주→2주, 가동률 86→88%), 미확정 사항(C사 승인 일정, A사 2차 라인 통보), 3안 비교 |
| set_B | B1 파일럿 결과(9/18) → B2 보안·비용 검토(9/30) → B3 확산 로드맵(10/5) | 사내 AI 코딩 도구 도입 | 일정 갱신(보안심사 9월 말 예정 → 10월 초 완료), 2안 비교(장·단점 표), 단계별 예산 증가, 손익분기(약 233석) |

- `*.txt`가 원문이고 `*.docx`는 `doc2report convert -p formal`로 만든 사내 정식보고서 서식 입력본이다.
- `종합_초안.txt/.docx`: 3건을 하나로 종합한 **초안**. 이 샌드박스에는 온프렘 LLM이 없어 **Claude가 직접 쓴 것**(도구 출력 아님)이다. 사람이 고쳐 정답으로 쓴다.
- 종합 원칙: 같은 항목의 값이 달라지면 **가장 최근 문서의 값**을 쓰고 이전 값은 변화로 남긴다. 미확정은 미확정으로 쓴다(단정 금지). 출처 표기는 없다(사용자 결정).
- 사실 대조: `transform/factcheck`로 종합본 수치를 원문과 대조(불일치 0, 오탐 2건은 원문에 근거 있음). 원문에서 일부러 뺀 수치는 이전 시점 값·파생값(2.5주, 12, 86%, 95%, 130, 210, 270, 2025 / 30, 62, 900)이다.
