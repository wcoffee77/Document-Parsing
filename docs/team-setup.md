# 팀원용 설치·사용 안내 (doc2report)

각자 **자기 PC에 설치해서 자기 토큰으로** 쓰는 방식이다(공용 서버 없음). 토큰은 사람마다 다르고
자기 PC에만 보관된다.

## 1. 받기

```powershell
git clone <저장소 주소> doc2report
cd doc2report
```

인터넷이 막힌 PC는 [onprem-first-run.md](onprem-first-run.md)의 "오프라인 설치"(wheelhouse)
절차로 설치한다. 인터넷이 되면 `uv sync` 한 번이면 된다.

## 2. 켜기

`start_webapp.bat`을 더블클릭한다. 검은 창(서버)이 뜨고 브라우저가 자동으로 열린다.

- 검은 창에 `http://127.0.0.1:8765/?k=…` 주소가 나온다. **끝의 `k=…`는 내 PC 전용 접속 열쇠**라
  다른 사람에게 알려 주지 않는다. 브라우저를 닫았다가 다시 열 때는 이 주소를 쓰거나 bat을 다시 실행한다.
- 열쇠 없이 `http://127.0.0.1:8765/`로 열면 "잠겨 있습니다" 안내만 보인다(정상).

## 3. 사용자 등록 (처음 한 번)

처음 열면 **사용자 등록** 창이 뜬다(나중에는 화면 오른쪽 위 `사용자: 이름` 을 눌러 고친다).

| 칸 | 넣을 값 |
|---|---|
| 사용자 이름 | 내 이름 |
| Confluence REST 주소 | 팀 안내로 받은 REST 게이트웨이 주소(`…/rest/api/`) |
| 개인 액세스 토큰(PAT) | Confluence → 오른쪽 위 프로필 → **개인 액세스 토큰** → 토큰 만들기. 만료일을 짧게(예: 90일) 잡는 것을 권장 |
| 로그인 이메일 | 사내 Confluence(Server/DC)는 **비워 둔다** |
| 온프렘 LLM 주소·모델명 | 팀 안내 값. LLM을 안 쓰면 비워 둔다 |

**저장하고 토큰 확인**을 누르면 Confluence에 "이 토큰의 주인이 누구냐"를 물어 화면 위에
`Confluence: 홍길동 (hong.gd)의 토큰 …abcd` 처럼 표시한다. 등록한 이름과 토큰 주인이 다르면 노란색으로
경고한다 — 남의 토큰이 들어가 있다는 뜻이니 바로 고친다.

## 토큰은 어떻게 보호되나

| 위험 | 막는 방법 |
|---|---|
| 저장소 폴더를 복사·공유하거나 실수로 git에 올림 | 토큰은 저장소 폴더가 아니라 **내 Windows 사용자 폴더**(`%APPDATA%\doc2report\account.json`)에만 저장 |
| 그 파일이 다른 PC나 다른 계정으로 새어 나감 | **Windows DPAPI 암호화** — 같은 PC의 같은 Windows 로그인 계정에서만 풀린다 |
| 화면·로그에 토큰이 보임 | 서버는 토큰을 브라우저로 돌려보내지 않는다. 끝 4자리만 표시 |
| 사내망 우회(PowerShell) 때 명령 기록·보안 로그에 토큰이 남음 | 토큰은 명령 문자열이 아니라 그 프로세스 환경변수로만 넘긴다 |
| 다른 PC에서 내 서버에 접속 | 서버는 `127.0.0.1`(내 PC)에서만 열린다 |
| 같은 PC의 다른 사용자·다른 프로그램이 내 서버로 변환 | **접속 열쇠**(`?k=…`)가 있는 브라우저만 API를 쓸 수 있다. 열쇠 파일도 내 사용자 폴더에 있다 |
| 악성 웹사이트가 내 브라우저를 시켜 서버를 호출 | 전용 헤더 확인 + 주소(Host)가 127.0.0.1/localhost가 아니면 거절(DNS 리바인딩 차단) |

남는 위험: 잠기지 않은 내 PC를 다른 사람이 직접 쓰는 경우는 막지 못한다(자리를 비울 때는 Windows 잠금 `Win+L`).
토큰이 샜다고 의심되면 Confluence에서 그 토큰을 **폐기**하고 새로 만들어 등록한다. 등록을 지우려면
등록 창의 **등록 삭제**를 누른다.

## 업데이트

```powershell
git checkout main
git pull origin main
```

그 다음 검은 창을 닫고 `start_webapp.bat`을 다시 실행한다(등록 정보는 그대로 남는다).
