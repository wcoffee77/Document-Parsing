# 정식보고서 가이드라인 채굴 — 1단계 (probe)

정식보고서 .docx 말뭉치에서 **서식·형식·문장 통계**를 뽑는다. LLM은 아직 쓰지 않는다(숫자는 파이썬이 정확하다).

```powershell
# 말뭉치는 저장소 밖에 둔다 (기밀). 결과 폴더도 저장소 밖을 권장.
uv run doc2report probe D:\corpus\정식보고서 -o D:\corpus\_probe
```

- 결과: `probe_summary.md`(사람용) · `probe_summary.json` · `probe/docNNN.json`(문서별)
- 기본은 **원문 글자와 파일 이름을 뺀다**(`--keep-text`, `--keep-names`로 켬). 문장 끝 두 글자만 집계에 들어간다.
- DRM이 걸린 .docx는 zip이 아니라 건너뛰고 이유를 남긴다 → Word에서 열어 다시 저장한 사본으로 다시 돌린다.
- `out/probe`(기본값)는 .gitignore 대상이지만, **저장소가 public이면 결과물도 커밋하지 말 것.**

뽑는 것: 용지·여백, 글꼴·크기·장평(글자 수 가중), 줄간격·단락 간격·정렬, **빈 줄(빈 문단) 사용**, 말머리별 실제
들여쓰기·굵기, 문장 길이·종결 형태(합쇼체·개조식·명사 종결), 날짜·수치 표기, 표(머리행 음영·정렬), 머리말·꼬리말(쪽번호),
목차·텍스트 상자(결재란).

`parsers/docx_reader.py`를 안 쓰는 이유: 변환용 파서라 빈 문단·서식 값·머리말·텍스트 상자를 IR 계약상 버린다.
서식은 스타일 체인을 풀어 **실효값**(직접 서식 > 번호 수준 > 스타일 > docDefaults)으로 읽는다.
