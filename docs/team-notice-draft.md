# 부서원 안내문 (초안)

메신저·메일에 붙여 넣는 용도. `[ ]`는 보내기 전에 채운다. 사내 주소·IP는 저장소가 public이라 일부러 적지 않았다.
자세한 설치·문제 해결은 [team-setup.md](team-setup.md).

---

**[doc2report 사용 안내]**

Confluence 페이지나 메모를 사내 규격 보고서(Word)로 바꾸거나, 여러 문서를 요약·종합해 새 보고서를 만드는 도구입니다. 각자 PC에서 실행하며, 내 토큰과 문서는 내 PC 밖으로 나가지 않습니다.

**1. 설치 (처음 한 번, 약 5분)**
1. Git for Windows가 있는지 확인합니다. 없으면 설치해 주세요.
2. 원하는 폴더에서 명령 창(cmd)을 열고 아래를 입력합니다.
   ```
   git clone https://github.com/wcoffee77/Document-Parsing
   ```
3. 받아진 `Document-Parsing` 폴더의 **`start_webapp.bat`** 을 두 번 눌러 실행합니다.
   - **파이썬 실행 환경(runtime)은 이때 자동으로 설치됩니다.** 따로 설치할 것이 없습니다.
   - 처음에는 검은 창에 `Downloading the Python runtime…`이 뜨고 1~2분 걸립니다. 정상이니 닫지 말고 기다려 주세요.
   - 끝나면 브라우저가 자동으로 열립니다.

(선택) 폴더의 `exclude_samples.bat` 을 한 번 실행하면 시험용 샘플 문서가 내 폴더에서 숨겨집니다. 안 해도 동작에는 문제가 없습니다.

**2. 처음 사용할 때**
- 화면 위 안내 띠의 **[등록]** 에서 아래를 입력합니다. 서식 변환(원문 그대로 규격만 바꾸기)은 등록 없이도 됩니다.
  - 이름
  - Confluence 주소와 **본인 개인 토큰**: [토큰 발급 방법 기재]
  - 보고서 작성(AI 요약·종합)을 쓸 경우 LLM 주소와 모델명: [주소·모델명 기재]
- 토큰은 PC에 암호화되어 저장되고, 화면 위에 누구의 토큰인지 표시됩니다. **다른 사람의 토큰을 쓰지 마세요.**

**3. 사용법**
1. 입력을 넣습니다. Confluence 주소, Word 파일, 붙여 넣은 글이 가능하고, 여러 개를 함께 넣을 수 있습니다.
2. 작업을 고릅니다.
   - **보고서 작성**: 여러 문서를 읽어 핵심만 담은 새 보고서를 만듭니다.
   - **서식 변환**: 내용은 그대로 두고 사내 규격 서식만 맞춥니다.
3. 출력 서식(보고서 양식 / Confluence 출력)을 고르고 실행합니다.
4. 결과가 나오면 화면에서 바로 열 수 있습니다.
   - **"확인이 필요한 항목"** 이 나오면 그 부분은 원문과 대조해 주세요. AI가 바꾼 내용 중 사실이 달라질 우려가 있는 곳 등을 알려 줍니다.
   - **"✓ 점검 이상 없음"** 이어도 최종 제출 전에 한 번은 읽어 보세요.

**4. 업데이트**
검은 창을 닫고 → 폴더에서 `git pull` → `start_webapp.bat` 을 다시 실행합니다. (프로그램이 바뀌었는데 이전 창이 열려 있으면 화면이 반쯤 깨질 수 있습니다. 꼭 닫아 주세요.)

**5. 안 될 때**
- 먼저 폴더의 **`doctor.bat`** 을 두 번 눌러 보세요. 설치용이 아니라 **점검용**이며, 점검 결과와 해결 방법이 나옵니다. (PowerShell에서 입력할 때는 `.\doctor.bat`)
- 해결이 안 되면 `doctor.bat` 결과를 [담당자]에게 보내 주세요.
- 문서에 사내 정보가 들어 있으므로 결과 파일을 사외로 보내지 마세요.

## 보내기 전에 정할 것
1. 저장소 공개 여부 — 지금 public이다. 사내 게이트웨이 주소·IP가 문서에 들어 있다(CLAUDE.md 참고). 비공개로 돌리면 부서원에게 GitHub 접근 권한을 따로 줘야 한다.
2. 빈칸 — 토큰 발급 방법, LLM 주소·모델명, 문의 담당자.
3. `exclude_samples.bat`은 선택 사항이라 설치 단계 밖(선택 칸)에 뒀다.
